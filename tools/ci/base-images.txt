# Every non-comment line is the exact image reference a workflow consumes:
# the build matrix in .github/workflows/release-packages.yml (which greps
# this file for its matrix pin before building), the root-install job of
# .github/workflows/c-cpp.yml, the asn1c gate container of
# .github/workflows/asn1c-regen.yml and the per-distribution install smoke
# matrix of .github/workflows/install-smoke.yml (issue #493). tools/ci/check-image-digests.sh scans
# every workflow and fails when an image is floating, unrecorded here, or
# recorded here but unused, so the two cannot drift apart silently.
#
# Dependabot cannot see these pins (they are not in a Dockerfile), so drift
# is detected by .github/workflows/base-image-refresh.yml: once a day it runs
# tools/ci/refresh-base-images.sh --check, which resolves every tag below to
# its current upstream digest and fails on a moved tag or on a pinned digest
# the registry no longer serves (quay.io drops the previous
# centos:stream9 manifest on every retag, issues #587/#590); it then proposes
# the --write repin as one pull request (or, without a dedicated token, one
# issue carrying the diff).
#
# Pins are name:tag@sha256:<index-digest>; the index digest must cover both
# linux/amd64 and linux/arm64 (the arm64 matrix leg runs natively on the
# ubuntu-24.04-arm runner, issue #421). An image with no arm64 build upstream,
# pulled only on amd64 runners (archlinux: the install smoke matrix), says so
# with a trailing `# platforms: linux/amd64`, which refresh-base-images.sh
# honours instead.
# Refresh every pin with: bash tools/ci/refresh-base-images.sh --write
# Refresh a single pin with:
digest-source: docker buildx imagetools inspect <image>:<tag>
