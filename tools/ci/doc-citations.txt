# doc-citations.txt — the anchor of every `path:line` citation in docs/*.md
# (issue #582, F-DOCS-009), checked by tools/ci/check-doc-citations.py from
# scripts/validate-doc-drift.sh (the doc-validators job).
#
# Records are TAB-separated (format: the header of check-doc-citations.py):
#   cite      <page> <path:range> <head-needle> [<tail-needle>]
#   delegate  <page> <script that anchors the page's citations>
#   exempt    <page> <reason>
#
# A needle is a fixed substring the range's first (head) or last (tail) line
# must hold. Moved code: update the line numbers in the page and here, then
# re-read the cited lines. Changed code: re-verify what the page says before
# changing the needle.

# Append-only records: each entry describes the tree on its date, and the
# log may not be rewritten (docs/DECISIONS.md, docs/troubleshooting.md headers).
exempt	docs/DECISIONS.md	append-only decision log
exempt	docs/troubleshooting.md	append-only troubleshooting log

# per heuristic entry. This checker still resolves each of their ranges.
